# Atelier: Technical Architecture & Build Guide

This document contains the deeply technical, granular details required to build the Atelier application. Pass this context directly into Claude Code to accelerate the implementation.

## 1. System Overview & Tech Stack
**Atelier** is a hybrid Human-AI fashion agent that automates the pipeline from trend identification to supplier procurement.

*   **Frontend (Creative Director Dashboard)**: Next.js (TypeScript), TailwindCSS, Framer Motion (for high-end Vibe Generation UX).
*   **Backend Orchestrator**: FastAPI (Python) or Next.js API Routes.
*   **AMD Cloud Inference**:
    *   **Text/Orchestration**: Llama-3-70B running on `vLLM` (Optimized for AMD ROCm).
    *   **Vision**: LLaVA (for analyzing fashion trends from images).
    *   **Diffusion**: Flux.1 or Stable Diffusion XL (for generating garment concepts).
*   **Business Logic & Automation**: Evolus AI REST API.

## 2. Core Data Models

To ensure strict data passing between the models and Evolus, enforce these JSON schemas:

```typescript
// The output from the LLaVA Vision Model after analyzing a trend
interface TrendAnalysis {
  trendName: string;
  coreSilhouettes: string[];
  colorPalette: string[]; // Hex codes
  keyFabrics: string[];
  commercialViabilityScore: number; // 1-100
}

// The core document generated by the LLM (vLLM)
interface TechPack {
  garmentName: string;
  description: string;
  billOfMaterials: {
    material: string;
    quantity: string;
    targetCostPerUnit: number;
  }[];
  measurements: Record<string, string>; // e.g. { "chest": "42in", "length": "28in" }
  targetSupplierRegion: string;
}
```

## 3. The Step-by-Step Workflow Pipeline

### Step 1: Trend Ingestion (Vision)
*   **Trigger**: User uploads a mood board, or the system scrapes an Instagram fashion feed.
*   **Action**: Pass the image(s) to the LLaVA endpoint running on AMD.
*   **Output**: Structured JSON (`TrendAnalysis`).

### Step 2: Generative Design (Diffusion)
*   **Trigger**: The Orchestrator takes the `TrendAnalysis` and creates a Diffusion prompt.
*   *(Example Prompt: "High fashion editorial photography, isolated on white background, a jacket featuring [coreSilhouettes], colored in [colorPalette], made of [keyFabrics]. Unreal Engine 5 render, highly detailed.")*
*   **Output**: 4 high-resolution image URLs.

### Step 3: Human Approval (The "Vibe" Check)
*   **Trigger**: The frontend displays the 4 images.
*   **Action**: The human user clicks "Approve" on one design. 

### Step 4: Evolus Orchestration (The Business Agent)
This is the core requirement of the hackathon track. Once approved:
1.  **Tech Pack Generation**: The FastAPI backend sends the approved image and trend data to the Llama-3-70B model (running via vLLM on AMD ROCm). The LLM generates a complete `TechPack` JSON.
2.  **Evolus API - Supplier Outreach**: 
    *   The backend calls the Evolus REST API to trigger a predefined Workflow.
    *   The Workflow uses the `TechPack` variables to draft an email.
    *   *(Example Email: "Hello [Supplier], we are looking to manufacture 500 units of [garmentName]. Please find the Bill of Materials attached...")*
3.  **Evolus API - MCP Shopify Push**:
    *   The Evolus agent utilizes an MCP (Model Context Protocol) tool to push the generated Image, Name, and Description directly to a Shopify store as a "Pre-order" product. (Original plan; as built, see CONTRACT.md.)

## 4. Evolus Integration Setup

You must drive Evolus via APIs. You will need:
1.  `EVOLUS_WORKSPACE_ID`
2.  `EVOLUS_API_KEY`
3.  `AMD_VLLM_ENDPOINT` (Your OpenAI-compatible endpoint URL for the AMD hosted model).

**Evolus Endpoint to Trigger Workflow:**
`POST https://api.evolus.ai/v1/workflows/{workflow_id}/execute`
*Payload:*
```json
{
  "inputs": {
    "tech_pack": "{...}",
    "image_url": "..."
  }
}
```

## 5. Development Milestones for Claude Code
Instruct Claude Code to build in this order:
1.  **Scaffold the Backend**: Setup FastAPI. Create dummy endpoints that return hardcoded `TrendAnalysis` and `TechPack` JSON to unblock the frontend.
2.  **Scaffold the Frontend**: Build the Next.js dashboard. It must look premium (use dark mode, sleek typography, subtle animations) to win the "Vibe Generation" prize.
3.  **Wire the AMD Endpoints**: Replace the dummy data in FastAPI with actual HTTP calls to the Llama-3/LLaVA endpoints (use standard OpenAI python SDK pointing to the custom AMD base URL).
4.  **Wire the Evolus API**: Implement the `httpx` or `requests` calls to trigger the Evolus workflow once the user hits "Approve" on the frontend.
